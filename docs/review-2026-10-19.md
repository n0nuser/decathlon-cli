Each finding is classed as **H** (fix before shipping), **M** (should fix) or **L** (document).

## Checked, no change needed

- **Several brands on a category listing** (`f-brand_quechua/f-brand_simond`): the site returns the union (87 = 67 + 20). Live-checked.
- **Missing fields:** no product in the three listing fixtures (120 products) has a zero price or an empty brand, model or title, so lenient decoding is not hiding anything today.
- **Env-only secrets:** there are none; the CLI has no credentials.
- **Session and state file modes:** `session.json` is 0600 (test), `state.db` is 0600, and directories are 0700.
- **MCP argument injection:** values are passed as `--flag=value`, with positionals after `--`. Unknown or mistyped arguments are refused (`TestArgv`).
- **Issue links** carry the command path only (no search terms), even from MCP.
- **Crash safety:** events are printed and delivered before state is committed, in one transaction.
