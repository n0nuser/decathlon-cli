## `decathlon mcp`

Serve the read commands to an agent over MCP (stdio)

```bash
decathlon mcp
```

Serve search, product, store, category and watch tools over the Model
Context Protocol on stdin/stdout. Each tool runs the matching command, so its
output is the command's JSON. Register it with 'decathlon mcp install'.

Tools: search, product_show, store_list, store_stock, category_list, watch_list, watch_check.

### `decathlon mcp install`

Register `decathlon mcp` with claude-code, codex or cursor

```bash
decathlon mcp install HARNESS
```
