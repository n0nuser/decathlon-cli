## `decathlon doctor`

Check config, FlareSolverr, the session and that decathlon.es answers

```bash
decathlon doctor [flags]
```

Check that everything a request needs works: config parses, sinks are
valid, FlareSolverr answers, a session exists (or can be minted), and a
plain request with it reaches decathlon.es. --mint forces a new session.
Exit 1 if any check fails.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--mint` | bool | `false` | discard the stored session and mint a new one |
