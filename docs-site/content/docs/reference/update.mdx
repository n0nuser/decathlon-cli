## `decathlon update`

Update decathlon to the latest stable release

```bash
decathlon update [flags]
```

Check GitHub for the latest stable release and replace this binary with it,
after verifying the archive against the release's checksums.txt. --check only
reports. Development builds and package-manager installs are not replaced.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--check` | bool | `false` | only report whether an update exists |
| `--yes` | bool | `false` | update without asking |
