## `decathlon search`

Search products, or list a category, with the website's filters

```bash
decathlon search [keywords...] [flags]
```

Search products by keywords, or list a category with --category.

Every filter the website shows works: the common ones have flags, the rest go
through --filter key=value, with keys and values as listed by
'decathlon search filters'. Keyword searches that match a category (such as
"tienda campaña") are redirected by the site to that category, which also
offers the store and delivery filters.

Pass the REF column (ref in JSON) to 'product show', 'store stock' and
'watch add product'.

```bash
decathlon search "tienda campaña" --format pretty
decathlon search "hornillo gas" --brand campingaz --max-price 40 --sort price_asc
decathlon search --category deportes/camping/tiendas-campana --store 169 --delivery 48h
decathlon search --category deportes/camping/tiendas-campana --filter "Nº de plazas=2 plazas"
decathlon search "botas montaña" --pages 3 --format jsonl | jq -r .url
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--brand` | stringArray | - | brand, repeatable (any brand the page lists) |
| `--category` | string | - | list a category instead of searching keywords (path from `decathlon category list`) |
| `--delivery` | string | - | only products delivered within 24h or 48h (category listings only) |
| `--filter` | stringArray | - | any other filter the page offers, as key=value, repeatable (see `decathlon search filters`) |
| `--limit` | int | `0` | stop after this many products (0: whole pages) |
| `--max-price` | float64 | `0` | maximum price in euros |
| `--min-price` | float64 | `0` | minimum price in euros |
| `--page` | int | `0` | result page to start from (0-based, 40 products each) |
| `--pages` | int | `1` | how many pages to fetch |
| `--sort` | string | - | relevance, price_asc, price_desc, discount, rating, newest (newest: categories only) |
| `--store` | string | - | only products in stock at this store (id or name; category listings only) |

### `decathlon search filters`

List the filters and values a search or category offers

```bash
decathlon search filters [keywords...] [flags]
```

List the filters a search or category page offers. KEY (or LABEL) and any
value's label go into --filter key=value. Keyword searches and category
listings offer different filters; only categories have store and delivery.

```bash
decathlon search filters "hornillo gas" --format pretty
decathlon search filters --category deportes/camping/tiendas-campana --format pretty
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--category` | string | - | category path |
