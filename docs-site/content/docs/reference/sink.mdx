## `decathlon sink`

Notification targets declared in config

Sinks are declared in config.toml and named by watches with --notify:

```
[sinks.phone]
type = "ntfy"
url = "https://ntfy.sh"
topic = "my-decathlon-alerts"
```

```
[sinks.discord]
type = "webhook"
url = "https://discord.com/api/webhooks/..."
template = "discord"
```

```
[sinks.script]
type = "exec"
command = ["/home/me/bin/on-decathlon-event"]   # event JSON on stdin
```

### `decathlon sink list`

List sinks and config problems

```bash
decathlon sink list
```

### `decathlon sink test`

Send a sample event to a sink

```bash
decathlon sink test NAME
```
