## `decathlon category`

Browse the category tree

### `decathlon category list`

List the navigation menu's categories with the paths --category takes

```bash
decathlon category list [flags]
```

List the storefront's navigation menu. PATH is what --category takes in
'search' and 'watch add search'. The menu is cached for a day.

```bash
decathlon category list --format pretty
decathlon category list --depth 3 --format jsonl | jq -r .path
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--depth` | int | `2` | levels to show |

### `decathlon category show`

Show a category's size and its subcategories

```bash
decathlon category show PATH
```

Show a category: how many products it lists and which subcategories it has,
with their product counts. Browse further with the subcategory paths, and
list products with 'decathlon search --category PATH'.

```bash
decathlon category show deportes/camping --format pretty
```
