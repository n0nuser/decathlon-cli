## `decathlon store`

Physical stores and which of them hold a product

### `decathlon store list`

List stores, optionally nearest first

```bash
decathlon store list [flags]
```

List Decathlon's stores in Spain from the store locator (cached for a day).
--near sorts by distance from a point; config 'location' is the default.

```bash
decathlon store list --format pretty
decathlon store list --near 40.4168,-3.7038 --limit 5 --format pretty
decathlon store list --city madrid
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--city` | string | - | only stores whose city, province or name contains this |
| `--limit` | int | `0` | show at most this many |
| `--near` | string | - | sort by distance from LAT,LNG |

### `decathlon store show`

Show one store's address, phone and opening hours

```bash
decathlon store show STORE
```

### `decathlon store stock`

Show which stores hold each size of a product

```bash
decathlon store stock PRODUCT [flags]
```

Show which physical stores hold a product, per colour and size. PRODUCT is
a product URL or GROUP/MODEL from 'search'.

Without --store, every store that holds a size is listed. With --store
(repeatable, id or name; config 'stores' is the default), only those stores
are checked; --all also prints the sizes they do not hold. The site says
whether a store holds a size, never how many.

```bash
decathlon store stock 303295/8513471 --near 40.4168,-3.7038 --limit 10 --format pretty
decathlon store stock 336529/8668913 --size 41 --store 169 --store Badalona --all
decathlon store stock 303295/8513471 --format jsonl | jq -r 'select(.in_stock) | .store_name'
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--all` | bool | `false` | with --store, also list sizes the stores do not hold |
| `--limit` | int | `0` | show at most this many lines |
| `--model` | string | - | only this model (colour) id; default: every model |
| `--near` | string | - | sort stores by distance from LAT,LNG (default: config location) |
| `--size` | string | - | only this size, as the site labels it ("42", "M", "Talla única") |
| `--store` | stringArray | - | only these stores (id or name), repeatable; default: config stores |
