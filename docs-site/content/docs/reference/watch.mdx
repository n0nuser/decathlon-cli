## `decathlon watch`

Watch products and searches for price and stock changes

Watch a product (price, online availability, per-store stock) or a search
(new products, price changes). Watches live in a local database. Each check
prints the events it found and sends them to the watch's sinks.

Event types: product.new, product.price_changed, product.removed, sku.new, sku.back_online, sku.sold_out_online, store.in_stock, store.out_of_stock.

```bash
decathlon watch add product 303295/8513471 --store 169 --name tent --notify phone
decathlon watch add search "hornillo gas" --max-price 30 --name stoves
decathlon watch check --format jsonl | jq -r 'select(.type=="store.in_stock") | .store.name'
decathlon watch run --interval 30m
```

### `decathlon watch add`

Create a watch

#### `decathlon watch add product`

Watch a product's price, online availability and store stock

```bash
decathlon watch add product PRODUCT [flags]
```

Watch a product. PRODUCT is a URL or GROUP/MODEL (GROUP/MODEL narrows it to
that colour). Reports product.price_changed, sku.new, sku.back_online,
sku.sold_out_online, store.in_stock, store.out_of_stock and product.removed.

--store limits store events to those stores (config 'stores' is the
default); with neither, every store's changes are reported.

```bash
decathlon watch add product 303295/8513471 --store 169 --name tent
decathlon watch add product 336529/8668913 --size 41 --store Badalona --name boots --notify phone
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--emit-initial` | bool | `false` | report what exists now as events, instead of a silent baseline |
| `--interval` | duration | `0s` | how often `watch check` considers it due (default: config watch.interval or 30m, minimum 5m) |
| `--model` | string | - | only this model (colour) id |
| `--name` | string | - | watch name (letters, digits, - and _), required |
| `--notify` | stringArray | - | sink from config to deliver events to, repeatable |
| `--size` | string | - | only this size |
| `--store` | stringArray | - | stores whose stock to report (id or name), repeatable |

#### `decathlon watch add search`

Watch a search or category for new products and price changes

```bash
decathlon watch add search [keywords...] [flags]
```

Watch a search. It takes the same keywords and filters as 'search', and
reports product.new and product.price_changed across the first --pages pages.

```bash
decathlon watch add search "hornillo gas" --max-price 30 --name stoves
decathlon watch add search --category deportes/camping/tiendas-campana --store 169 --name tents-pamplona
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--brand` | stringArray | - | brand, repeatable (any brand the page lists) |
| `--category` | string | - | list a category instead of searching keywords (path from `decathlon category list`) |
| `--delivery` | string | - | only products delivered within 24h or 48h (category listings only) |
| `--emit-initial` | bool | `false` | report what exists now as events, instead of a silent baseline |
| `--filter` | stringArray | - | any other filter the page offers, as key=value, repeatable (see `decathlon search filters`) |
| `--interval` | duration | `0s` | how often `watch check` considers it due (default: config watch.interval or 30m, minimum 5m) |
| `--max-price` | float64 | `0` | maximum price in euros |
| `--min-price` | float64 | `0` | minimum price in euros |
| `--name` | string | - | watch name (letters, digits, - and _), required |
| `--notify` | stringArray | - | sink from config to deliver events to, repeatable |
| `--pages` | int | `1` | result pages to watch (1-5) |
| `--sort` | string | - | relevance, price_asc, price_desc, discount, rating, newest (newest: categories only) |
| `--store` | string | - | only products in stock at this store (id or name; category listings only) |

### `decathlon watch check`

Check due watches once and print their events

```bash
decathlon watch check [NAME...] [flags]
```

Check the named watches, or every watch that is due (--all: every watch).
Prints the events (a JSON array; one per line with --format jsonl), sends
them to sinks, and stores the new state. Exit 0 when nothing changed.

Run it from cron or a systemd timer:
```
*/30 * * * * decathlon watch check --format jsonl >> ~/decathlon-events.jsonl
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--all` | bool | `false` | check every watch, due or not |

### `decathlon watch events`

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--limit` | int | `50` | at most this many (0: all) |
| `--since` | duration | `0s` | only events newer than this (e.g. 24h) |

### `decathlon watch run`

Check due watches in a loop until interrupted

```bash
decathlon watch run [flags]
```

Run due checks in the foreground, waking every --interval (plus up to 10%
jitter). Events stream to stdout one per line. Stop with Ctrl-C.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--interval` | duration | `30m0s` | how often to wake up |
